# 多宫格海报提示词主模板（poster-template）

三个变体：**基础版（徒手）/ 兵器版 / 对打版**。

变量用 `{{xxx}}` 标注，Step 3 阶段必须全部替换为具体描述，**不能留任何 `{{}}` 字面**。

输出时必须是**纯中文文本**，不带 markdown 装饰符号、不带编号符号、不带英文引号。

> ⚠️ **填充原则（反硬编码）**：模板里所有 `{{xxx}}` 不是简单字符串替换，而是**根据用户输入定制描述**。
> - `{{人物三个面部锚点}}` 不是套固定模板（如永远写"剑眉星目、面色清冷、长发束起"），而是根据角色（年龄、性别、性格、气质、影视参考）写具体且差异化的特征。
> - `{{招式 N}}` 必须按 SKILL.md Step 2 的"动态生成原则"动态产出，不要从骨架照抄；起势 / 收势招必须从仪式感动作池中根据角色调性选择。
> - `{{服装}}` `{{场景}}` 等都要根据用户输入和影视参考做差异化描述，不要套用任何固定句式。
> - 每次生成必须使整段提示词与上次同题材生成有可观察的差异（人物锚点 / 服装细节 / 招式名 / 动作要点 / 景别分配 等至少 1-2 项明显不同）。

> ⚠️ **白模 pre-vis 优先（默认填充原则）**：演武者**默认填充为「纯白色 3D 白模人形 / 线框模型 / 木质人偶 / 黑色剪影 / 灰模」**等抽象人形，**不绑定具体角色外貌**——这是武指 pre-vis 工作流的标准做法（参考迪士尼 / 漫威 / Yuen Wo Ping 团队的预演流程），既规避版权风险又让动作设计独立于角色 IP，同一份动作可 retarget 到任意最终角色。
>
> - 仅当用户在 Step 1 明确选择「角色化最终画面」时，才把 `{{人物长相风格}}`、`{{服装}}` 等填充为具象角色描述；
> - 否则一律用「纯白色 3D 白模人形 / 表面无纹理 / 关节线条清晰」+「头束简洁布带 / 腰系窄腰带 / 持械护手」等极简符号填充；
> - **武器 / 场景 / 调性 / 武术体系 / 镜头语言 / 强化关键词等其他字段不受白模影响**，仍按用户输入正常填充——白模只替代「角色具象外貌与服装」，动作精度 / 武器形态 / 镜头节奏 / 对手剪影全部保留。

## 变体 A｜基础版（徒手）

```
生成一张高完成度的「{{宫格规格}} 的 {{N}} 宫格 {{武术体系}} 武术动作分解海报」，核心要求：

- 画面为 {{宫格规格}} 的 {{N}} 宫格排版，每一格对应一个连续武术动作步骤，编号 1-{{N}}。
- 整体不是普通教学图，而是带有 {{调性定语}} 的武术动作分镜海报，兼具电影武指感与海报视觉冲击力。
- 演武者为同一位 {{人物长相风格}} 的 {{年龄性别}}，{{人物体型描述}}，{{人物三个面部锚点}}，全程保持同一人物，不要每格都换人。
- 景别多样性：约 {{近景特写格数 = ⌈N/8⌉}} 格使用近景或特写（聚焦 {{特写焦点：手印 / 剑尖 / 眼神 / 兵器局部 等}}），{{低角度格数 = ⌈N/8⌉}} 格使用低角度仰拍或俯拍，其余使用站立全景；避免 {{N}} 格全部同一景别。
- 风格为 {{武术体系}} + {{影视参考风格关键词}}，动作要有 {{节奏特质}}。
- 服装为 {{服装材质 + 颜色 + 款式}} + {{配饰}}，整体高级，有质感不浮夸。
- 背景为 {{场景描述}}，{{氛围光描述}}，但不要太复杂，主体仍然清晰，每格背景保持一致。
- 每一格都要有：大号阿拉伯数字步骤编号（明显放大、置于格子角落）、中文招式标题（黑体加粗）、简洁中文要点说明（10-20 字、轻量字体）、动作方向箭头或重心轨迹线（细线条、不抢主体）。
- 箭头和排版要清晰，像专业武术指导工作单 / 动作说明板。
- 动作顺序要有连贯感，依次为：{{招式 1}}、{{招式 2}}、{{招式 3}}、……、{{招式 N}}。
- 每个动作在朝向、重心、肢体张开度、发力部位上明显不同，不能只是轻微换姿势；要像一整段完整套路被拆解成 {{N}} 步。
- 画面整体精致、统一、清爽，兼具武术教学板的功能性、影视武指海报的张力、套路分镜的连贯感。

版式要求：
- {{宫格规格}} 整齐分布，格子边框清楚，格间距均匀。
- 字体简洁有力，中文清晰可读，编号字号最大、招式名居中、要点说明最小。
- 每格人物全身清楚可见，不能裁掉脚部、拳脚末端或头顶。
- 同一人物、同一套服装、同一系列风格、同一光线方向。

整体效果参考：{{3-5 个风格关键词}}。
```

## 变体 B｜兵器版

在变体 A 基础上，**新增**「兵器锚定块」插在「服装」之后：

```
- 兵器为 {{兵器名称}}：{{材质 + 颜色 + 长度 + 关键细节}}，每一格都必须出现，且兵器在格间保持同一外观；兵器在动作中扮演核心角色，{{兵器运动特征：刀光弧线 / 棍头方向 / 枪口指向 / 鞭身波浪}}。
```

并把【动作连贯句】中的招式名替换为含兵器动作的招式（如"劈棍""拔刀斩""双枪交叉射击"）。

招式列表里至少 80% 的格子要有兵器主导动作；徒手过渡招式（如"持械礼""收兵礼"）只占首尾。

## 变体 C｜对打版（双人对练）

把【演武者】块替换为：

```
- 画面有两位演武者：A {{A 人物完整描述}}，B {{B 人物完整描述}}。两人风格 {{相同 / 对立}}，全程保持各自外观不漂移。每格中两人空间关系要明确（距离、朝向、谁主动谁被动），动作要构成攻防对应。
```

把【动作连贯句】改成 A B 互动序列：

```
- 动作顺序为 A 与 B 的攻防对练：{{招式 1：A 起势 / B 起势}}、{{招式 2：A 进攻 / B 反应}}、{{招式 3：B 反击 / A 防御}}、……、{{招式 N：定格亮相}}。
```

每一格的招式名要写成"A 直拳 + B 闪身格挡"这种攻防对的形式。

## 字数参考与排查

主提示词目标长度：**700-1050 中文字符**。

- 不到 700 字：调性 / 服装 / 场景 / 招式名词中至少有一项写得太空，或者强化关键词（动态/法术/手部/对手）漏掉了
- 超过 1050 字：招式描述句太啰嗦，把每招的"一句话要点"压到 5-8 字内

**自动排查 checklist**：

- [ ] `{{}}` 字面已全部替换
- [ ] 招式名按编号顺序全部出现
- [ ] 调性定语只用一种、不混用
- [ ] 人物三锚点已写出（如"短马尾、英气剑眉、修长比例"）
- [ ] 服装含材质 + 颜色 + 款式
- [ ] 兵器（如有）外观描述完整、且在动作连贯句中至少出现 2 次
- [ ] 背景明确、氛围光明确、不喧宾夺主
- [ ] 每一格的差异化要求写明（朝向 / 重心 / 张开度 / 发力部位）
- [ ] 字数在 600-900 中文字符
- [ ] 整段无 markdown 装饰、无英文引号、无参数符号
